# Hazard Shield Dashboard

Build HazardShield GIS from the attached specification, starting with the requested first slice: enable the data foundation, simple email/password login, and a polished government/disaster-management dashboard with an interactive Leaflet map as centerpiece, habitation markers, hazard polygons, filters, data table/list, and add/edit habitation form. Implement the Section 6 rule-based scoring precisely, including configurable normalized weights, spatial proximity via Turf, density normalization, terrain scoring, capacity status, and green/amber/red risk states that update automatically on entry/edit. Use demonstration data where needed and make it ready for later screens.
